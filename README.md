# 50 оттенков Рустема

Ироничный лендинг об электронике в эстетике кинопостера. Статический HTML, CSS и JavaScript без сборки и внешних зависимостей во время работы. Шрифты размещены локально.

Запуск из корня:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173. Форма открывает почтовый черновик или копирует бриф. Сайт не принимает и не сохраняет заявки.

Публикация: GitHub Pages из корня ветки `main`. `.nojekyll` отключает обработку Jekyll. Все пути к ресурсам относительные, поэтому сайт работает в подкаталоге репозитория.

Публичный адрес: https://igormitrofanov.github.io/50_shadows_of_Rustem/

Дизайн: [telltale](https://github.com/IgorMitrofanov/telltale-design). Визуальные решения и терминология описаны в DESIGN.md. Исходные референсы оставлены в корне без изменений.
